O Briefing

Vocês foram contratados para criar a presença digital de uma nova marca. Pode ser um produto inovador, uma empresa de tecnologia ou um destino turístico sustentável.

ESTRUTURA Obrigatório

  • Header com Navegação
  • Seção Hero Impactante
  • Grade de Funcionalidades (Grid Layout)
  • Seção de Depoimentos (Flexbox)
  • Rodapé com Links

TECNOLOGIAS Obrigatório

  • HTML5 Semântico
  • Uso de Flexbox para componentes
  • Uso de Grid para o layout geral
  • Cores e Fontes Personalizadas
