Flexbox: Unidimensional

O Flexbox trabalha com uma dimensão de cada vez (linha ou coluna). É perfeito para alinhar itens em um único eixo e criar distribuições flexíveis.

  • Distribuição: Itens expandem ou contraem dinamicamente.
  • Ordem: Mude a ordem visual sem mexer no HTML.
  • Alinhamento: Controle total nos eixos Main e Cross.

Use para: Menus, barras de ferramentas e layouts lineares.

⊞

CSS Grid: Bidimensional

O Grid trabalha com duas dimensões simultaneamente (linhas e colunas). Ideal para estruturas complexas e precisas.

  • Posicionamento: Coloque itens em qualquer célula da grade.
  • Espaçamento: Distribuição automática de espaço entre células.
  • Sobreposição: Elementos podem se sobrepor facilmente.

Use para: Dashboards, layouts de páginas inteiras e galerias.

🚀 Resumindo: Use Flexbox para alinhar itens em uma direção e Grid para layouts complexos em duas dimensões. Na prática, você vai combinar ambos para criar interfaces sofisticadas!

A Regra de Ouro ✨

Nenhuma propriedade de alinhamento funciona se você não definir primeiro: display: flex ou display: grid. Ele é o gatilho que ativa o comportamento do container.

Quando usar Flexbox?

  • Alinhamento simples (centralizar algo).
  • Menu de navegação.
  • Barra de ferramentas.
  • Layouts lineares.

Quando usar Grid?

  • Layouts complexos de página inteira.
  • Sistemas de Galeria.
  • Dashboard com áreas variadas.
  • Sobreposição de elementos.
